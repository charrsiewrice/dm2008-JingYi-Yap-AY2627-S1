### The Project

<PAIRWORK WITH WANJING 
We created a Totoro-themed version of the classic Flappy Bird game, inspired by My Neighbour Totoro. Instead of the original bird, players control Totoro as he navigates through obstacles in a whimsical, nature-inspired setting. We made it my own by designing and incorporating customised visual assets, including Totoro, houses and illustrated obstacles, to create a playful game environment that reflects the charm of the film.
Beyond the basic game mechanics, we customised the visual experience by replacing the original bird and pipes with my own Totoro-inspired illustrations and environmental assets. We also implemented a personalised game-over screen with custom typography, a final score display and a restart button. On the coding side, we developed the collision detection, score tracking and restart functionality, allowing players to replay the game without refreshing the page.>

### ✍️ Reflection

<We initially set out to create a Totoro-themed version of the classic Flappy Bird game, where players control Totoro and navigate through obstacles. We wanted to move beyond simply recreating the original game mechanics by giving it a distinct visual identity inspired by "My Neighbour Totoro". We was quite happy with how the final result turned out, especially how the customised illustrations, background and overall colour palette came together to create a more playful and cohesive experience.
Our sketch responds to two main inputs: the spacebar and mouse clicks. Pressing the spacebar makes Totoro flap upwards while gravity continuously pulls him downwards. Players earn points by successfully passing through obstacles. If Totoro collides with an obstacle or reaches the boundaries of the screen, the game transitions into a game-over state. Players can then restart using either the spacebar or the restart button.
One of our biggest challenges was implementing the game states and making sure the restart function worked properly. We had to understand how to reset variables such as the score, spawn counter and pipes, while creating a new bird object so that each attempt started fresh. We also had to work through positioning my image assets and ensuring that the collision detection aligned with the customised visuals.
If We had more time, We would explore adding more interactive animations, sound effects and different obstacle designs to make the gameplay more engaging. We would also like to introduce a high-score feature to encourage players to keep improving their scores.>
